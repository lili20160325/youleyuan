# 星灯游乐园 · 午夜闭园

给孩子玩的网页密室：闭园后被锁在星灯游乐园里，沿着过山车、鬼屋「悄悄话」、兑奖屋找回电源，并弄清是谁关了电。

- 玩法：一条主线、12 处连成一片的场景。点物件观察、拿道具、开锁、组合；密码都藏在现场证据里，也会遇到假线索。
- 机关小游戏：兑奖屋抓娃娃、镜宫找不同。
- 适合小学高年级。鬼屋是惊喜，不恐怖；结局是温暖的反转。
